# Sanshray Shetty — Portfolio

A responsive, single-page personal portfolio with a black/red visual theme.

## Files
- `index.html` — page structure
- `styles.css` — styling and responsive layout
- `script.js` — navigation and scroll interactions
- `profile.png` — custom black/red portrait used in the hero section

## Publish free with GitHub Pages
1. Extract this ZIP.
2. Open your GitHub repository and choose **Add file → Upload files**.
3. Upload the *contents* of this folder (the four files above), not the containing folder.
4. Commit the upload to the `main` branch.
5. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
6. Wait for the Pages deployment to finish. Your site should appear at `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.

Important: `index.html`, `styles.css`, `script.js`, and `profile.png` must all sit together at the repository root.

## Customise
- Replace the placeholder LinkedIn URL in `index.html` with your profile URL.
- Add your public email in `script.js` by setting `CONTACT_EMAIL`.
- The project cards currently describe capability areas, not specific client deployments.
