# Sanshray Shetty — Portfolio

A responsive, single-page portfolio built with plain HTML, CSS and JavaScript. No build tools, paid hosting, or framework required.

## Preview locally
Open `index.html` in a browser. Google Fonts load from the internet; the page still works with fallback fonts offline.

## Free publishing (GitHub Pages)
1. Create a free account at https://github.com/ and create a new **public** repository, e.g. `sanshray-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. GitHub will publish the site at `https://YOUR-USERNAME.github.io/sanshray-portfolio/`.

## Alternative: Netlify Drop
Visit https://app.netlify.com/drop and drag the extracted project folder onto the page. Netlify provides a free `*.netlify.app` address.

## Before publishing
- In `script.js`, replace the empty `CONTACT_EMAIL` value with the email address you want public.
- Replace the generic LinkedIn URL in `index.html` with your profile URL.
- The three work cards describe capability areas, not verified client deployments. Replace them with real, shareable projects when ready.

## Files
- `index.html` — content and page structure
- `styles.css` — visual design, responsive layout and animation
- `script.js` — navigation, reveal effects and contact configuration
